# Design and Analysis of Algorithms

## Overview

A collection of Python implementations developed as part of coursework in Design and Analysis of Algorithms.

## Topics Covered

* File Processing
* Pattern Matching
* CSV Data Search
* Matrix Operations
* KMP String Matching Algorithm
* Merge Sort
* Insertion Sort
* Algorithm Performance Analysis

## Key Experiments

### KMP Pattern Matching

Implementation of the Knuth-Morris-Pratt algorithm and comparison with naive string matching.

### Sorting Algorithm Analysis

Empirical comparison of Merge Sort and Insertion Sort using execution time and comparison counts.

## Technologies Used

* Python
* CSV Module
* Time Module

## Learning Outcomes

* Understanding algorithm efficiency
* Comparing time complexity of algorithms
* Implementing classical searching and sorting techniques
